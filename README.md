# 📊 Introdução à Análise e Visualização de Dados com Python

Material do curso **Introdução à Análise e Visualização de Dados com Python**, desenvolvido para apresentar os principais conceitos e ferramentas utilizados no processo de análise de dados, desde a exploração e preparação até a comunicação dos resultados.

O curso combina conceitos de **Ciência de Dados, Estatística Descritiva, Análise Exploratória de Dados (EDA), visualização e storytelling**, utilizando Python como ferramenta para transformar dados em informações e evidências que apoiem a tomada de decisões.

## 🎯 Objetivos

Ao final do curso, espera-se que o participante seja capaz de:

* Compreender os principais conceitos de Ciência de Dados;
* Diferenciar população, amostra e variáveis;
* Identificar diferentes tipos de variáveis;
* Aplicar medidas de tendência central e dispersão;
* Compreender a importância da qualidade dos dados;
* Identificar inconsistências, valores ausentes e outliers;
* Realizar uma Análise Exploratória de Dados (EDA);
* Manipular dados utilizando Python;
* Construir diferentes tipos de visualizações;
* Escolher gráficos adequados de acordo com o tipo de dado e objetivo da análise;
* Interpretar padrões, tendências, distribuições e relações nos dados;
* Transformar análises em narrativas utilizando **data storytelling**.
